# WebToApkConverter Icons

This directory should contain two icon files for the WebToApkConverter application:

1. `app_icon.png` - The main application icon showing a web-to-mobile conversion concept
2. `default_icon.png` - A simple Android icon used as the default for generated APKs

## Icon Creation Instructions

To create these icons:

1. Use a graphics editor that supports PNG with transparency (Adobe Photoshop, GIMP, etc.)
2. Follow the material design guidelines
3. Create each icon at 256x256 pixels with proper transparency
4. Use the specified color schemes:
   - App Icon: Blue (#3498db) and green (#2ecc71)
   - Default Icon: Gray (#95a5a6)
5. Save the files in this directory with the exact filenames shown above

See the full specifications in the ICON_SPECIFICATIONS.md file in the resources directory.

## Important Note

These icons are essential for the proper functioning and visual identity of the application. If you're having trouble creating them, you might consider:

1. Using an icon generator/creator tool online
2. Hiring a designer on a freelance platform
3. Using open-source icon libraries with appropriate licensing
